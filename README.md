# Hindustan Unilever Ltd. – FP&A Performance Dashboard

## Overview

A practical FP&A (Financial Planning & Analysis) dashboard built using **Excel and Power BI** to analyze Hindustan Unilever Ltd.'s financial performance through **Actual vs Budget vs Rolling Forecast** analysis.

The project simulates a corporate FP&A workflow covering historical financial analysis, budgeting, variance analysis, rolling forecasting, KPI monitoring, and management-oriented financial insights.

> **Note:** Financial data used in this project is based on publicly available information and is used strictly for educational and portfolio purposes. This project is not an official report of Hindustan Unilever Ltd.

## Objective

* Analyze historical financial performance
* Build quarterly budgets using historical financial drivers
* Compare **Actual vs Budget** performance
* Calculate **₹ and % variances**
* Prepare a **Rolling Forecast** based on recent performance trends
* Track Revenue, EBITDA, EBIT and Net Profit performance
* Identify key cost and profitability drivers
* Present management-ready insights through Power BI

## Data & Methodology

The Excel model contains historical quarterly financial data and FP&A analysis covering:

* Revenue
* Expenses
* Operating Profit / EBITDA
* EBIT
* Other Income
* Interest Expense
* EBT
* Tax
* Net Profit

### Budgeting

Budget assumptions are developed using historical averages such as:

* Revenue Growth %
* Expenses as % of Revenue
* EBITDA Margin
* EBIT Margin
* Other Income as % of Revenue
* Interest as % of Revenue
* Tax as % of Revenue

These drivers are applied to forecast the upcoming quarters.

### Variance Analysis

The model compares:

**Actual vs Budget**

and calculates:

* Variance in ₹
* Variance in %
* Favorable / Unfavorable performance
* Revenue and cost drivers
* Profitability impact

### Rolling Forecast

A rolling forecast is prepared using the latest available financial performance and updated assumptions to provide a forward-looking view of expected performance.

## Power BI Dashboard

The dashboard focuses on key FP&A KPIs:

* Revenue Growth %
* EBITDA Margin %
* EBIT Margin %
* Net Profit Margin %
* Revenue – Actual vs Budget vs Rolling Forecast
* EBITDA – Actual vs Budget vs Rolling Forecast
* EBIT – Actual vs Budget vs Rolling Forecast
* Net Profit – Actual vs Budget vs Rolling Forecast
* Quarterly Variance Analysis
* Cost and Profitability Analysis

## Key FP&A Insights

* Revenue performance is monitored against budget to identify growth variances.
* Expense performance is analyzed against revenue to identify cost pressure.
* EBITDA and EBIT trends are used to evaluate operating profitability.
* Net Profit is analyzed to understand the combined impact of operating performance, other income, interest and tax.
* Rolling Forecast provides a forward-looking view for management planning.
* Variance analysis helps identify key financial drivers requiring management attention.
